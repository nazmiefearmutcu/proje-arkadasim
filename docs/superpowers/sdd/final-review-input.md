## A. Rulings that require a code change (the fix wave must implement these)

- **R1 — Dev-only reset link (task 4).** When `NODE_ENV !== "production"` and `SMTP_URL` is empty, the console mailer prints the password-reset URL unredacted, so `/sifremi-unuttum` → `/sifre-sifirla/[token]` can be walked through locally. Production (or any SMTP transport) never logs tokens. This is the only exception to the global "never log tokens" constraint. Keep the existing redaction for everything else.
- **R2 — Team visibility for guests/unverified viewers (task 7).** The owner's university stays visible to everyone (spec §4.4 card lists it). For guests and unverified viewers, the team member list on `/projeler/[id]` uses the same "Ad S." masking as the owner (spec §2), hides department, and does not link to profiles (profiles are verified-only, spec §3.2). Verified viewers and admins see full names, department and profile links.
- **R3 — Focus suggestions as chips (task 3).** Spec §3.1 says "Odaklanınca öneri çipleri görünür": the search bar's focus panel renders suggestions as wrapping chips (tap height ≥ 44 px), not full-width rows. Tapping still searches `suggestionToQuery(suggestion)`.
- **R4 — Mock provider in production fails at startup (task 5, spec §5.2).** Add `src/instrumentation.ts` with `register()` that throws a clear Turkish/English error when `NODE_ENV === "production"` and `VERIFIER_PROVIDER === "mock"`. Keep the service's MANUAL_REVIEW fallback as a second line of defence. Unit-test the check as a pure function.
- **R5 — One AI-consent text naming DeepSeek and China (task 6).** Registration, `/dogrulama` consent panel and `/ayarlar` must all use the spec §4.1 wording ("Maskelenmiş belge metnimin yapay zeka incelemesi için yurt dışına (DeepSeek, Çin) aktarılmasına açık rıza veriyorum.") from one shared constant (e.g. in `src/config/legal.ts`), with the link to `/kvkk/acik-riza`.
- **R6 — No self-review by admins (task 6).** `approveAttemptAction` / `rejectAttemptAction` refuse when the attempt belongs to the acting admin (Turkish error, nothing changes). Add a test.
- **R7 — Remove unused env variables (task 12).** `SESSION_SECRET` and `ADMIN_EMAILS` are read by no code: remove them from `.env.example` and README (table, setup steps, go-live checklist). Keep the guards test that proves `ADMIN_EMAILS` grants nothing.
- **R8 — No missed messages in polling (task 9).** The chat poll must not drop two messages with the same millisecond `createdAt`: use `createdAt >= after` (or a (createdAt, id) cursor) and de-duplicate by message id on the client.
